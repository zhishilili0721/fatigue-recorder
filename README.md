# 疲労実験レコーダー

ブラウザーで使う実験手順・回答・反応時間の記録ツールです。単一の index.html で動作します。

## 利用

被験者IDと条件を設定し、「記録開始」を押します。各手順の時刻、KSS・VAS・PVT・NASA-TLXの記録をCSVで保存できます。

作業後の順序：作業終了 → KSS・VAS → PVT → NASA-TLX → 歩行②。基線と休憩後の順序は元の設定を維持しています。

記録はブラウザーのローカルストレージに保存されます。別端末や以前のclaude.ai・ローカルHTMLの記録は自動同期されません。終了後はCSVを保存してください。実験記録やCSVをこの公開リポジトリへアップロードしないでください。

外部フォント・API・Claudeの機能に依存しません。GitHub Pagesの公開元はmainブランチのルートです。
